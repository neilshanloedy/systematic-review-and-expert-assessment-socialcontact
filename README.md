# On conducting diary-based social contact surveys to inform transmission models of close-contact infections: a systematic review and expert-informed questionnaire

## Overview
This repository contains the R code accompanying the manuscript entitled *"On conducting diary-based social contact surveys to inform transmission models of close-contact infections: a systematic review and expert-informed questionnaire"*.

The study combines a systematic review of diary-based social contact surveys conducted between 2018 and 2025 with a structured expert assessment to develop an updated, expert-informed questionnaire and recommendations for future social contact surveys.
The code provided in this repository was used to process and analyse the data and generate the figures presented in the manuscript and its Supporting Information.

## Repository contents
The repository is organised as follows:

- **`R/`**: R scripts used to analyse the data and generate the figures presented in the manuscript.
- **`data/`**: Data files required to reproduce the analyses, where applicable.
- **`README.md`**: Description of the repository and instructions for using the code.

## Data availability
The data underlying the systematic review and expert assessments findings are provided in the manuscript and its Supporting Information files.
The expert assessment results are available in aggregated form. Individual-level expert responses are not publicly available, in accordance with the data protection arrangements for the study.
Please refer to the manuscript's Data Availability Statement for further details.
